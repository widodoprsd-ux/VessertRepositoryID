# Internal UI

Self-contained UI system. Hand-written CSS. Hand-drawn SVG. Hand-encoded PNG, ICO, BMP.

No npm install. No node_modules. No vendor. No Tailwind. No CDN. No Google Fonts. No font download. No external SVG source.

## Requirements

- Node.js 18 or newer (only external runtime)

## Build

    node build.js

Or:

    npm run build

Dependencies are empty so npm install does nothing and creates no node_modules.

## Serve

    node serve.js

Serves dist/ on http://localhost:8080.

## Full flow

    node build.js && node serve.js

## What is internal

- CSS written by hand in css/
- SVG icons drawn by hand in svg/
- PNG, ICO, BMP encoded by build.js using zlib and custom chunks
- Sprite generated by build.js
- Entry JS and CJS generated by build.js
- Hash manifest generated by build.js
- Fonts use system stack

## What is forbidden

- npm install of any dependency
- git clone of any source
- downloading fonts, icons, or CSS from any CDN
- importing from lucide, heroicons, tabler, feather, fontawesome, material

## VessertID naming

    vessert-<family>-<name>-<variant>

See VESSERT-ID.md for the full spec.

## Adding an icon

1. Draw an SVG into svg/icons/vessert-icon-<name>-<variant>.svg
2. Follow VessertID naming
3. Run node build.js
4. Use in HTML: use href="/vessert-sprite.svg#vessert-icon-<name>-<variant>"

## Formats handled

Generated by build.js:
- PNG, ICO, BMP (via custom encoders in build.js)
- SVG sprite (from svg/)

Copied by build.js:
- woff, woff2, ttf, otf (fonts)
- webp, avif, jpg (photos)
- mp4, webm (video)
- any binary you place in assets/source/

Written by hand:
- css, html, js, cjs, json, xml, txt, webmanifest
