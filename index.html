6. Supported Formats

Native

Every single font is produced into individual files:

  • .woff2 — Brotli / Modern web (compressed)
  • .woff — zlib Deflate web format
  • .ttf — TrueType sfnt table binary
  • .otf — OpenType sfnt binary
  • .eot — Embedded OpenType binary
  • .svg — W3C SVG 1.1 Font vector XML

Built for zero external

Everything lives in this repository. Nothing reaches the internet at build time.

Zero npm

build.js uses only fs, path, zlib, crypto from Node built-ins.

Zero external SVG

Every icon drawn by hand. No Lucide, no Heroicons, no Tabler.

Zero Tailwind

Utility classes written by hand in css/04-utilities.css.

All formats handled

Generated by build.js from code, or copied and hashed if binary.

Generated from code

  • PNG via zlib deflate and manual chunks
  • ICO wrapping multiple PNG sizes
  • BMP with 24-bit BGR rows
  • SVG sprite from hand-drawn icons
  • WOFF2, WOFF, TTF, OTF, EOT, SVG fonts

Copied and hashed

  • woff, woff2, ttf, otf, eot fonts
  • webp, avif, jpg photos
  • mp4, webm video
  • any binary in assets/source

Written by hand

  • css, html, js, cjs
  • json, xml, txt
  • webmanifest
  • svg icons and illustrations
